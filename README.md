# تطبيق لايف للتعدين — أندرويد

تطبيق أندرويد لطلب منتجات لايف للتعدين عبر واتساب (249910578325). الصفحة مضمّنة داخل التطبيق في
`app/src/main/assets/www/` فتفتح فوراً حتى مع ضعف الإنترنت.

## الأسعار من Google Sheets
1. في Google Sheets ارفع `LifeMining_Prices.xlsx` (في جذر المستودع) (ملف ← استيراد). الأعمدة: id | name | category | unit | price | available.
2. عدّل `price` (أرقام بالجنيه) و`available` (نعم/لا). الخلية الفارغة = «السعر عند الطلب». لا تغيّر `id`.
3. شارك الجدول: أي شخص لديه الرابط — عارض.
4. ضع رابط الجدول في `sheetUrl` داخل `app/src/main/assets/www/products.js` (مرة واحدة) واعمل Commit.
بعدها كل تعديل في الجدول يظهر عند فتح التطبيق بدون إعادة بناء. إذا لم يتوفر الإنترنت يعرض آخر أسعار محفوظة.

## بناء APK عبر GitHub
1. أنشئ مستودعاً جديداً (Private) باسم LifeMining-App.
2. ارفع كل محتويات هذا المجلد (Add file ← Upload files) واضغط Commit.
3. افتح تبويب Actions — يبدأ البناء تلقائياً (5–8 دقائق).
4. من تبويب Releases (النسخة latest) حمّل `lifemining.apk` على الجوال وثبّته (فعّل التثبيت من مصادر غير معروفة).

## تغيير الرقم أو المنتجات
عدّل `products.js` (رقم الواتساب، المنتجات، الأقسام) ثم Commit؛ يُبنى APK جديد تلقائياً.

## النشر في Google Play (اختياري)
مثل مشروع سلة خضرواتي: حساب مطوّر + مفتاح توقيع في Secrets (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`).
اسم الحزمة `com.lifemining.app` لا يتغير بعد النشر.

## آيفون
ملف APK لأندرويد فقط. على الآيفون: انشر مجلد `app/src/main/assets/www` على GitHub Pages أو استضافة HTTPS، ثم Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.

## نسخة الآيفون (والمتصفح) عبر GitHub Pages
1. في المستودع: Settings ← Pages ← Source: **GitHub Actions** (مرة واحدة).
2. بعد اكتمال تشغيل «Deploy web app» يظهر الرابط: https://abobkar-eltayeb.github.io/LifeMining-App/
3. آيفون: افتح الرابط في Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».

## حفظ العملاء والطلبات في Google Sheet (نسخة 1.1)
عند أول طلب يسجّل العميل: الاسم، رقم الواتساب، المدينة، وموافقته على استلام العروض. تُحفظ بياناته على جهازه فلا يكتبها مرة أخرى.
كل طلب يُرسل إلى شيت خاص (غير شيت الأسعار) ويأخذ رقماً متسلسلاً LM-0001، ثم يُفتح واتساب برسالة فيها الرقم والأصناف والإجمالي وطريقة الدفع والاستلام.

1. ارفع `google-apps-script/LifeMining_Orders_Customers.xlsx` إلى Google Drive وافتحه كـ Google Sheet (ملف ← حفظ بتنسيق Google Sheets). **لا تشاركه مع أحد.**
2. من داخل الشيت: الإضافات ← Apps Script. احذف الموجود والصق محتوى `google-apps-script/Code.gs` واحفظ.
3. اختر الدالة `setup` واضغط Run، ووافق على الصلاحيات (حسابك أنت).
4. نشر ← نشر جديد ← النوع: تطبيق ويب ← التنفيذ باسم: أنا ← من لديه حق الوصول: أي شخص ← نشر. انسخ الرابط الذي ينتهي بـ `/exec`.
5. ضع الرابط في `ordersApiUrl` داخل `app/src/main/assets/www/products.js` واعمل Commit.

إذا انقطع الإنترنت لحظة الطلب يأخذ الطلب رقماً مؤقتاً بالتاريخ (مثل LM-261128-1430) ويُرسل للشيت تلقائياً عند فتح التطبيق لاحقاً.
عند تعديل Code.gs لاحقاً: نشر ← إدارة عمليات النشر ← تعديل ← إصدار جديد (حتى يبقى نفس الرابط).
طرق الدفع والاستلام تتغير من `paymentMethods` و`deliveryMethods` في `products.js` (أول خيار في الاستلام هو الذي يطلب عنوان التوصيل).
